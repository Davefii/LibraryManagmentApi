# Library Management System

ASP.NET Core Web API project built using:

- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- Repository Pattern
- Service Layer
- DTO Pattern
- Swagger

## Features

- Books Management
- Authors Management
- Categories Management
- Users Management
- User Profiles
- Members Management
- Borrowing System
- Return Book System
- Duplicate Borrow Prevention
- Maximum Borrow Limit
- Overdue Books Tracking
- Dashboard Statistics

## Architecture

3-Tier Architecture

Controller
→ Service
→ Repository
→ Database
